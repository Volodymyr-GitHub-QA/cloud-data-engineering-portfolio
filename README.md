# Cloud Data Engineering Portfolio

A hands-on portfolio focused on **Data Quality, Data Engineering, and AWS cloud technologies**.

## About

This repository documents my journey toward building practical cloud data engineering solutions, combining my experience in data quality engineering with AWS services, Python, and SQL.

The goal is to develop projects progressively, from local data validation tools to cloud-based data pipelines and more advanced data platforms.

## Project Roadmap

### 1. Data Quality Toolkit
**Level:** Beginner · **Status:** Planned

A Python-based toolkit for validating structured datasets.

Planned features:
- Schema and data type validation
- Null and duplicate detection
- Business rule validation
- Automated tests with pytest
- Data quality reports

### 2. AWS Data Quality Pipeline
**Level:** Intermediate · **Status:** Planned

A serverless data processing pipeline that applies data quality checks to incoming datasets.

Planned technologies:
- Amazon S3
- AWS Lambda
- Amazon CloudWatch
- Amazon Athena
- Python and SQL

### 3. Cloud Data Engineering Platform
**Level:** Advanced · **Status:** Planned

An extended data platform demonstrating reliable ingestion, orchestration, data quality monitoring, access control, and infrastructure automation.

The architecture and technology choices will be defined as the project evolves.

## Technology Stack

- **Languages:** Python, SQL
- **Cloud:** Amazon Web Services (AWS)
- **Data Engineering:** Data validation, ETL/ELT, data pipelines
- **Testing:** pytest, automated quality checks
- **Version Control & CI/CD:** Git, GitHub Actions

Technologies will be added as they are introduced and used in the projects.

## Cost Philosophy

The projects will prioritize free tools, local development, and cost-conscious cloud architecture. AWS resources will be introduced incrementally, with a target total experimental budget of **up to $50**.

## Progress

This portfolio is under development. Each project will include its objectives, architecture, implementation details, testing approach, and lessons learned.
